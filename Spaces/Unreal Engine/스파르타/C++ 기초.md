# C++ 기초

- 리소스 파일
    - 코드를 구현할 때 필요한 외부파일
    - 외부 자원을 사용할 때, 넣는 공간
- 소스 파일
    - .cpp, .c의 확장자를 갖는 파일
- 헤더 파일
    - 클래스 정의 등의 역할을 하는 파일이 있는 공간
    - c++에서 제공하는 라이브러리 파일
        - #inlcude<>의 형태로 추가
    - 사용자 정의 파일
        - #include ""의 형태로 추가 

- 배열
    - 배열을 통째로 대입하는 것은 불가능(컴파일 오류 발생)

- 포인터
    - 변수를 다른 변수에 대입을 하는 것은 복사를 하는 것이고 복사는 비용이 든다
    - 배열의 경우, 크기가 커지면 복사 비용이 부담이 될 수 있다
    -  값을 담지 않고 변수의 주소값을 담는다
    -  메모리의 주소값을 알면 해당 공간을 직접 제어한다
