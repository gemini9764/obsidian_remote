# C++ 기초

- 리소스 파일

    - 외부 자원을 사용할 때, 넣는 공간
- 소스 파일
    - .cpp, .c의 확장자를 갖는 파일
- 헤더 파일
    - 클래스 정의 등의 역할을 하는 파일이 있는 공간
    - c++에서 제공하는 라이브러리 파일
        - #inlcude<>의 형태로 추가
    - 사용자 정의 파일
        - #include ""의 형태로 추가 

- 배열
    - 배열을 통째로 대입하는 것은 불가능(컴파일 오류 발생)
